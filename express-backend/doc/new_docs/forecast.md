# Forecast API

Serves predictive demand modeling data.

## Endpoints

### 1. `GET /api/forecast/kpi`
Returns top-level forecast KPIs (accuracy, horizon, peak demand).

### 2. `GET /api/forecast/summary`
Returns summary statistics (confidence ranges, historical accuracy, trend direction).

### 3. `GET /api/forecast/main-chart`
Provides the time-series arrays for historical vs predicted demand visualization.

### 4. `GET /api/forecast/trend`
Provides 7-day and 30-day growth trends and volatility classification.

### 5. `GET /api/forecast/seasonality`
Provides weekly/monthly seasonal patterns and uplift percentages.

### 6. `GET /api/forecast/network`
Returns forecast data grouped by distribution centers.

### 7. `GET /api/forecast/skus`
Returns forecast data at the individual SKU level.

### 8. `GET /api/forecast/insight`
Provides AI-generated textual insights on the current forecast trends.

### 9. `GET /api/forecast/performance`
Provides accuracy metrics (MAPE, RMSE) comparing different AI models.

### 10. `GET /api/forecast/impact`
Returns financial impact metrics generated by following the forecast predictions.
